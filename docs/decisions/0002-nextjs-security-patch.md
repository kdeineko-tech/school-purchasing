# 0002. Оновлення Next.js 16.4.0 → 16.4.3 через вразливості безпеки

- Статус: прийнято
- Дата: 2026-10-25
- AC: — (стек; поведінку жодного AC не змінює)

## Контекст

Стек шаблону зафіксовано в `AGENTS.md` («Next.js 16.4… не оновлювати без ADR»). `npm run build` на 16.4.0 падає з
`SecurityFatalError`, а `npm audit` показує для `next >=16.0.0 <=16.4.0` три вразливості — дві критичні й одну
високої серйозності (класифікація GitHub Advisory Database; `npm audit` показує для пакета лише найвищу, critical):

- GHSA-2464-fhr4-w9xw (critical) — віддалене виконання коду без входу через Image Optimization API з SVG-файлами;
- GHSA-p3m5-59mp-jv5r (high) — відмова в обслуговуванні в App Router через Server Actions;
- GHSA-673q-mjm6-r5xr (critical) — віддалене виконання коду без входу у функціях `use cache`, що повертають typed arrays.

Застосунок використовує App Router і Server Actions (усі дії адміністратора, вхід), тож друга вразливість стосується
нас напряму; `next/image` і `use cache` ми не використовуємо, але маршрут `/_next/image` у збірці є.

## Рішення

- `next` і `eslint-config-next`: `16.4.0` → `16.4.3` (останній патч гілки 16.4 на 2026-10-25; виправлення — з 16.4.1).
- Інші версії стеку (React 19.3, TypeScript, ESLint, Supabase, Tailwind, Vitest) не змінюємо.
- Рядок «Next.js 16.4» у `AGENTS.md` лишається правдивим: мінорна версія та сама.

## Розглянуті варіанти

- Лишитися на 16.4.0 — збірка не проходить (`SecurityFatalError`), а прод на Vercel лишається вразливим.
- `next upgrade --agent=security` (пропонує сама збірка) — може змінити більше, ніж потрібно; ручне оновлення двох
  пакетів до патч-версії прозоріше в diff.
- Оновитися до новішої мінорної чи мажорної версії — шаблон курсу її не перевіряв; патч закриває вразливості без
  зміни API.

## Наслідки

- Патч-версія без змін API: код, `src/proxy.ts` і тести не змінюються; перевіряємо `npm run lint`, `npm run typecheck`,
  `npm test`, `npm run build` (має показати `ƒ Proxy (Middleware)`) і preview на Vercel.
- Наступні виправлення безпеки в гілці 16.4 — так само патчем із доповненням цього ADR; перехід на іншу мінорну
  чи мажорну версію — новим ADR.
