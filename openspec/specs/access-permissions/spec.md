# access-permissions Specification

## Purpose
Сторінки адміністратора відкриті лише адміністраторам, а дозволи на типи заявок і закупівель працюють однаково для
всіх: працівник без ролі `admin` має лише видані йому дозволи, адміністратор — усі типи й усі відділи.

## Requirements

### Requirement: Сторінки адміністратора лише для адміністраторів

IF користувач без ролі `admin` відкриває список працівників чи налаштування відділів, THEN the system SHALL не
надавати доступу і показати повідомлення «Недостатньо прав».

#### Scenario: AC-ORG-09 Користувач без ролі admin на сторінці адміністратора

- **GIVEN** користувач без ролі `admin`
- **WHEN** він намагається відкрити список працівників чи налаштування відділів
- **THEN** доступу немає
- **AND** він бачить повідомлення «Недостатньо прав»

### Requirement: Дозволені типи заявок працівника

The system SHALL показувати в профілі працівника без ролі `admin` серед дозволених типів заявок лише ті типи, на які
адміністратор видав йому дозвіл.

#### Scenario: AC-ORG-17 Працівник із дозволом на «Витрату карткою»

- **GIVEN** працівник без ролі `admin`, якому адміністратор видав дозвіл на «Витрату карткою»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів заявок є «Витрата карткою»

#### Scenario: AC-ORG-26 Працівник без дозволу на «Витрату карткою»

- **GIVEN** працівник без ролі `admin` і без дозволу на «Витрату карткою»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів заявок «Витрати карткою» немає

### Requirement: Типи заявок адміністратора

The system SHALL показувати в профілі адміністратора серед дозволених типів заявок «Витрату карткою», «Запит на
чек» і «Рахунок постачальника» незалежно від виданих йому дозволів.

#### Scenario: AC-ORG-25 Адміністратор без дозволу на «Витрату карткою»

- **GIVEN** адміністратор без дозволу на «Витрату карткою»
- **WHEN** адміністратор відкриває його профіль
- **THEN** серед дозволених йому типів заявок є «Витрата карткою»

### Requirement: Типи закупівлі працівника без дозволу

The system SHALL показувати в профілі працівника без ролі `admin` і без дозволу «Самостійна закупівля» серед
дозволених типів закупівлі лише «Відділ закупівель».

#### Scenario: AC-ORG-27 Працівник без дозволу «Самостійна закупівля»

- **GIVEN** працівник без ролі `admin` і без дозволу «Самостійна закупівля»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів закупівлі є лише «Відділ закупівель»

### Requirement: Вибір відділу адміністратором

WHEN адміністратор створює заявку «Закупівля» чи «Відшкодування», the system SHALL дозволяти йому обрати будь-який
відділ зі списку всіх відділів.

#### Scenario: AC-ORG-22 Адміністратор без відділів обирає відділ

- **GIVEN** адміністратор без жодного відділу
- **WHEN** він створює заявку «Закупівля» чи «Відшкодування»
- **THEN** він може обрати будь-який відділ зі списку всіх відділів

#### Scenario: AC-ORG-29 Адміністратор-заявник одного відділу обирає інший

- **GIVEN** адміністратор, який є заявником лише відділу «Початкова школа»
- **WHEN** він створює заявку «Закупівля» чи «Відшкодування»
- **THEN** він може обрати будь-який відділ зі списку всіх відділів, зокрема «Офіс»

### Requirement: Тип закупівлі для адміністратора

WHEN адміністратор створює закупівлю, the system SHALL дозволяти йому обрати будь-який тип закупівлі незалежно від
дозволу «Самостійна закупівля».

#### Scenario: AC-ORG-23 Адміністратор без дозволу «Самостійна закупівля»

- **GIVEN** адміністратор без дозволу «Самостійна закупівля»
- **WHEN** він створює закупівлю
- **THEN** він може обрати будь-який тип закупівлі, зокрема «Самостійна закупівля»
