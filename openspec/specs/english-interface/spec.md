# english-interface Specification

## Purpose
Усі тексти, які бачить користувач, показані англійською за таблицею PM, а ідентифікатори ролей, номери й дані, які ввели
люди, лишаються без змін.

## Requirements

### Requirement: Написи інтерфейсу англійською

The system SHALL показувати на кожній сторінці застосунку для будь-якої ролі всі написи інтерфейсу англійською за
таблицею ValiaBihun/2026-quitcode-dream-team#49 без жодного українського слова.

#### Scenario: AC-LANG-01 Будь-яка сторінка англійською

- **GIVEN** користувач будь-якої ролі, що відкриває будь-яку сторінку застосунку
- **WHEN** сторінка показана
- **THEN** усі написи інтерфейсу (заголовки, назви полів, кнопок і статусів, типи заявок, підказки, порожні стани) англійською за таблицею з «Припущень»
- **AND** жодного українського слова серед них немає

### Requirement: Сторінка входу англійською

The system SHALL показувати сторінку входу й повідомлення про помилку входу англійською.

#### Scenario: AC-LANG-02 Вхід англійською

- **GIVEN** гість без входу
- **WHEN** він відкриває сторінку входу або вводить неправильні дані для входу
- **THEN** сторінка входу й повідомлення про помилку входу показані англійською

### Requirement: Повідомлення англійською

The system SHALL показувати повідомлення про відмову й помилки введення англійськими текстами з таблиці
ValiaBihun/2026-quitcode-dream-team#49 замість українських.

#### Scenario: AC-LANG-03 Відмова без права англійською

- **GIVEN** працівник без права на дію (чужий відділ, налаштування для не адміністратора)
- **WHEN** він виконує цю дію або відкриває сторінку за прямим посиланням
- **THEN** він бачить повідомлення «Not enough permissions» замість «Недостатньо прав»
- **AND** воно не розкриває вміст заявки

#### Scenario: AC-LANG-04 Заявка без рядків англійською

- **GIVEN** заявка без жодного рядка
- **WHEN** заявник її подає
- **THEN** заявка не подається
- **AND** він бачить повідомлення «Add at least one line» замість «Додайте хоча б один рядок»

#### Scenario: AC-LANG-05 Рішення без причини англійською

- **GIVEN** схвалювач, який відхиляє заявку без причини
- **WHEN** він підтверджує рішення
- **THEN** рішення не зберігається
- **AND** він бачить повідомлення «Provide a reason» замість «Вкажіть причину»

### Requirement: Статуси англійською текстом

The system SHALL підписувати статус заявки, де його показано, текстом «Awaiting approval», «Approved» чи «Rejected», а
не лише кольором.

#### Scenario: AC-LANG-06 Підпис статусу

- **GIVEN** заявка в статусі «Очікує схвалення», «Схвалено» чи «Відхилено»
- **WHEN** її показано у списку, на сторінці заявки або в історії
- **THEN** статус підписано текстом «Awaiting approval», «Approved» чи «Rejected» відповідно, а не лише кольором

### Requirement: Ідентифікатори ролей без змін

The system SHALL показувати ідентифікатори ролей без змін, а підпис ролі — англійською назвою з таблиці
ValiaBihun/2026-quitcode-dream-team#49.

#### Scenario: AC-LANG-08 Ролі й номери

- **GIVEN** ролі `requester`, `approver`, `admin`
- **WHEN** вони показані на будь-якій сторінці
- **THEN** ідентифікатори ролей лишаються без змін
- **AND** поруч, де є підпис ролі, — англійська назва за таблицею
